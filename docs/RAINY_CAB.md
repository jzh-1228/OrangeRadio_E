# 雨夜车窗（Rainy Cab · 深夜行车）

> 情绪沉浸视觉模式：深夜行车后排视角——玻璃上雨滴滑行，窗外是专辑封面同色的
> 虚化霓虹 bokeh，歌词像写在雾玻璃上，旧句留成水痕字被缓缓冲淡。
> 定位是"情绪牌"：夜归、雨天、emo 慢歌时会想用的模式，画面感强到会想截图。

## 设计概念

现有视觉光谱里缺"深夜情绪档"：网易云情绪场景、lofi girl 的长时粘性都来自"陪伴感"而非"视觉表演"。雨夜车窗与流光（日常温柔）、胶片电台（怀旧）、涂鸦墙（张扬）形成完整的情绪光谱。

**克制三原则**（吸取风格电台下线的教训）：

1. 全场景只有「一块玻璃 + 一片光斑 + 一场雨」三样东西；
2. 光斑是散景圆（bokeh）而非建模城市——抽象化防廉价；
3. 色彩全部取自专辑封面。

## 画面分层

| 层 | 元素 | 实现 |
|---|---|---|
| L0 | 窗外光斑 | `#rainy-far-canvas` 低分辨率（1/3）Canvas 2D + CSS `blur(9px)`；夜空渐变基底下 **102 个三层纵深 bokeh**——L0 远灯（64 个小而亮的清晰点，色彩含暖白/冷白=路灯钠光与月光记忆）、L1 中斑（26 个霓虹光团）、L2 近晕（12 个大光晕），三层速度差（7~72px/s）制造"车在走"的视差，光斑带路面颠簸微浮动 |
| L1 | 玻璃雾气 | 纯 CSS 多层径向渐变（边角雾气 + 中央通亮聚焦区 + 暗角），静态零开销 |
| L2 | 雨滴 | `#rainy-glass-canvas` 全分辨率（dpr≤1.5）对象池，上限 150 |
| L3 | 歌词 | 雾玻璃逐字凝出（blur 7px→0）+ 水痕旧句层 |
| L4 | 仪表台剪影 | 纯 CSS 弧形深色剪影 + 缝隙微光线，"人坐在车里"的包裹暗示 |

## 物理细节（本模式的记忆点）

- **车身微颤只抖窗外**：bass 突增给弹簧注入冲量（幅度钳制 ±2.2px），仅窗外光斑层 `ctx.translate` 震动；玻璃上的雨滴与歌词相对不动——符合物理直觉，颤动才有"车"的实感。
- **歌词间隙雨变大**：当前无歌词行持续 >1.5s（间奏）→ 雨势平滑升至 1.7 倍——"歌停了，雨还在下"的留白。
- **副歌天际线泛暖**：chorus 闸门抬升夜空渐变底部的暖色分量。
- **霓虹闪烁**：treble 高时随机光斑 flare（远处灯牌偶尔闪一下）。
- **水痕字**：切行时旧句 DOM 移入 ghost 层，CSS 动画 7s 淡出 + 渐模糊——像被后续雨滴缓缓冲淡。

## 雨滴系统（WebGL2 shader 方案，照 rain-glass-demo 实现）

与 canvas 对象池完全不同的技术路线，**雨滴位置/滑落/拖尾全在 fragment shader 里计算**：

- **折射**（核心）：累积水珠遮罩 g0 的屏幕空间梯度（dFdx/dFdy）当法线，偏移 UV 采样背景纹理——这就是透镜折射的物理模拟，水珠内部自动清晰、边缘自动出轮廓。
- **滑落物理**：`smoothstep(holdT, 1.0, phase)` 蓄水-滑落时间线（前 35% 静止积重，之后 `pow(slide, 1.35)` 重力加速），横向蜿蜒正弦（低频摆动），蓄水期长大/收尾缩小/下落拉伸。
- **泪痕**：滑落路径上留下**连续渐细水线 + 零星随机残珠**（水线宽度沿路径抖动微微弯曲，残珠位置 hash 打散、约半数位置才出现——不再是等距珠串）。
- **汇聚**：滑落路径上的静态冷凝微滴被吸收减弱（大水珠经过处微滴让位，滑珠更亮）——模拟真实雨滴吸收小水珠。
- **折射参数调优**：`uRefract` 1.6（过强会把水珠上半部分拉空成半圆）、滑落拉伸上限 0.18、边缘压暗上限 0.38——三者的平衡保证水珠始终是完整圆形。
- **静态冷凝微滴**：缓慢凝结/闪现/蒸发，铺满玻璃做氛围底。
- **景深**：mipmap LOD（`textureLod`）——背景模糊、水珠内部清晰。
- 背景纹理 = far canvas（canvas 2D 光斑层，封面取色/车颤/副歌暖光保留），每帧 texImage2D 上传 + generateMipmap。
- 降级：WebGL2 不可用时 `initRainyGL` 返回 false，玻璃层透明只剩背景光斑，不崩。

## 动效设置（DIY 控制台 · 动效 tab ·「雨夜车窗」分组）

激活雨夜车窗时分组自动显示，退出自动隐藏（复用 Sonic 系列的条件显隐机制 `fx-sonic-hidden`）：

| 设置 | fx 字段 | 作用 |
|---|---|---|
| 雨的大小 | `rainIntensity` | 雨滴生成率倍率（0.18~2.78） |
| 雾气浓度 | `rainFog` | 玻璃 tint 层浓度（0.18~0.60）+ 窗外模糊度（7~16px） |
| 车流亮度 | `rainCity` | 光斑 alpha 倍率（0.5~1.4） |
| 车速 | `rainSpeed` | 横移视差倍率（0.55~1.65） |

四个字段全部走 fx 面板标准链路：绑定/重置按钮/持久化（autosave 白名单）/数值回显。

## 取色 / 音频 / 歌词

与流光同思路、独立实现（模块自包含，删除互不影响）：

- 取色：32×32 降采样 → HSL 24 桶 top3 + 最亮色作字色；失败静默回退默认夜色板。
- **鲜艳度补偿**（`rainyVividPalette`）：暗封面提亮主色（gain 上限 1.75 渲染端 alpha 增益）、灰调做 ±色相扩展；输出 6 色扩展板（3 主色 + 亮变体 + 暖白 + 冷白）供远灯光斑多样化——城市夜景即使灰调环境也有红绿灯/霓虹/路灯的多色记忆。
- 音频：`frequencyData` 自算 energy/chorus/bass（覆盖层期间主循环不更新全局特征值）。
- 歌词：复用 `tokenizeGraffitiText` + `computeGraffitiReveals`（YRC 真实时序/LRC 均分）；字体跟随用户歌词字体选择（`fx.lyricFont` → `lyricFontStackForKey`，与涂鸦墙一致，无需退出重进）；`audio` 为 null 时按 0 处理渲染首行。

## 生命周期（film-radio 范式）

- `body.rainy` + localStorage `orangesea-rainy-cab-v1`；四方互斥（胶片/涂鸦/流光）。
- 进入临时切 eco 质量档（退出恢复）；主循环覆盖判断命中后 3D 保温。
- rAF 节流 ~30fps（雨滴动效 30fps 无感差异）；双层画布，光斑层低频成本低。

## Do Not Regress

- 覆盖层背景必须**不透明**（Electron 下 `backdrop-filter` 不可靠）。
- 车身微颤幅度不得超过 2.2px，且**绝不**作用于玻璃雨滴层与歌词（物理一致性）。
- 光斑必须是散景圆，禁止引入立体建筑/城市建模元素。
- 取色失败必须静默回退，不允许阻断播放。
